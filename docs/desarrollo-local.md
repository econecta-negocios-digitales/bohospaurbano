# Desarrollo local

Entorno objetivo: Windows PowerShell.

Instalar dependencias desde la raíz:

```powershell
npm install
```

Ejecutar el sitio y el Studio en terminales separadas:

```powershell
npm run dev:web
npm run dev:studio
```

Validar y compilar:

```powershell
npm run typecheck
npm run build
npm run format:check
```

# Variables de entorno

Cada workspace tiene su propia configuración.

## Web

Usar `apps/web/.env.example` como referencia para `apps/web/.env`.

## Studio

Usar `apps/studio/.env.example` como referencia para `apps/studio/.env`.

Los archivos `.env` locales no se versionan. El Project ID de Sanity no se hardcodea en archivos TypeScript.

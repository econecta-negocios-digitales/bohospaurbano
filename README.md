# Boho Spa Urbano

Monorepo técnico inicial para el sitio público y Sanity Studio.

## Requisitos

- Node.js 24 LTS
- npm

## Instalación

```powershell
npm install
```

Copiar las variables de entorno de cada workspace desde su archivo `.env.example`.

## Comandos

```powershell
npm run dev:web
npm run dev:studio
npm run typecheck
npm run build
npm run format:check
```

La Etapa 1 contiene únicamente la inicialización técnica. No incluye diseño, contenido, schemas editoriales definitivos, formularios, SEO ni despliegue.
